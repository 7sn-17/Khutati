إصدار 0.8.3 — تحديثات أذكى، ورسائل صادقة، ونافذة تحديث أنيقة:

• فحص التحديثات الذكي: لا يطلب التطبيق من GitHub إلا بعد مرور ساعة كاملة على آخر فحص ناجح، فلا يستهلك حصة الطلبات أثناء التنقل بين الشاشات أو العودة إلى التطبيق.
• طلبات موفّرة: يحفظ التطبيق بصمة الإصدار (ETag) ويرسلها مع كل فحص، فإذا لم يتغير شيء يرد GitHub بأنه لا جديد دون أي استهلاك للحصة.
• بديل عند الحظر: إذا رفض GitHub الطلب (تجاوز الحد)، يقرأ التطبيق خلاصة الإصدارات العامة ويصل إلى أحدث إصدار منها.
• رسائل صادقة: عند الفحص اليدوي تظهر «أنت تستخدم أحدث إصدار» فقط إذا نجح الفحص فعلاً. وعند انقطاع الإنترنت أو فشل الطلب تظهر رسالة واضحة تطلب التحقق من الاتصال، ولا يدّعي التطبيق أبداً أنه محدّث.
• فحص صامت في الخلفية: إن فشل، لا يزعجك ولا يستهلك مهلة الانتظار، ويحاول مرة أخرى في المرة القادمة.
• نافذة التحديث: عُولج تقاطع العنوان في الأعلى، وكُبّر زر الإغلاق وأصبح في موضعه الصحيح، مع مساحة أوسع للنص.
• الأصوات: خُفّض مستوى المؤثرات الصوتية إلى النصف تقريباً لتبقى لمسة خفيفة لا مصدر إزعاج.
• الإصدار: 0.8.3 (33). بياناتك المحلية وخطتك تبقى محفوظة كما هي عند التحديث.
